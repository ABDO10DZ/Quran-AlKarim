# Quran Al-Karim (القرآن الكريم) Android App

A modern, offline-first Quran reader built with Jetpack Compose, Kotlin, and Material Design 3.

## Features
- Complete Quran text with Tajweed color coding option
- Audio recitations (Al-Hussary, Al-Afasy)
- Prayer times calculation & Qibla compass
- Bookmark management & Surah search
- Multilingual translation support (Arabic & English)

## Build Instructions
```bash
./gradlew assembleDebug
```
